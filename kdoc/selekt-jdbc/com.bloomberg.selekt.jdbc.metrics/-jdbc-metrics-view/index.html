JdbcMetricsView

class JdbcMetricsView(source)

Allocation-conscious live access to a data source's operational metrics.

Values are read independently and do not constitute an atomic snapshot. Use com.bloomberg.selekt.jdbc.driver.SelektDataSource.metrics when a self-consistent value object is preferred.
